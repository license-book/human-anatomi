# 우리 몸 한눈에 보기

일반인을 위한 한국어 2D 인체 도감 PWA.

## 개발

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

Build command: `npm run build`  
Output directory: `dist`

## 현황

첫 번째 프로토타입: 모바일 화면, 기관 검색, 전신 개념도 터치, 기초 설명, 즐겨찾기, PWA 설치 설정.

현재 그림은 위치를 단순화한 SVG 개념도이며, 검수된 정식 해부학 이미지로 교체할 예정입니다. 의료 진단용이 아닙니다.
